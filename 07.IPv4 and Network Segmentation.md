# IPv4 and Network Segmentation — What I Understood

IPv4 provides the **logical addressing system** used to identify devices on a network. Network segmentation is the process of dividing a larger network into smaller networks to make communication more organized and easier to manage.

### Key points I learned

* IPv4 addresses are **32 bits** and are written as four decimal numbers separated by dots.
* An IPv4 address has a **network portion** and a **host portion**.
* The **subnet mask** helps determine which part of the address represents the network.
* **Subnetting** allows one network to be divided into smaller networks.
* Each subnet has its own **network address** and **broadcast address**.
* Devices on different subnets normally need a **router or Layer 3 device** to communicate.
* Segmentation can reduce unnecessary traffic and make networks easier to manage.

### What I understood

I learned that network segmentation is not just about creating smaller IP ranges. It creates **separate logical networks**, allowing administrators to control how devices communicate with each other. Subnetting therefore helps use IPv4 addresses more efficiently while also improving network organization.
