# Network Access Media — What I Learn't

Network access media determines **how devices access and place data onto a network**. I learned that devices need rules for sharing the communication medium so that data can reach the intended destination.

### Key points I learned

* Devices communicate using different types of media, such as **Ethernet cables and wireless connections**.
* Ethernet uses **MAC addresses** to identify devices on the local network.
* A switch forwards Ethernet frames based on the **destination MAC address**.
* Wireless networks use radio signals instead of physical cables.
* The method used to access the medium depends on the type of network.

### What I understood

The main thing I learned is that network communication depends on both the **physical medium** and the rules used to access it. At the local network level, devices use **frames and MAC addresses** to communicate, while switches help deliver those frames to the correct device.
