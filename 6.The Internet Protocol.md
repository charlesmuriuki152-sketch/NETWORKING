# Internet Protocol — What I Understood

The **Internet Protocol (IP)** is responsible for addressing and delivering packets between devices across networks. I learned that IP allows devices to communicate even when they are not on the same local network.

### Key points I learned

* Every device communicating over an IP network needs an **IP address**.
* **IPv4** uses 32-bit addresses, while **IPv6** uses 128-bit addresses.
* The **subnet mask/prefix** helps determine which part of an address identifies the network.
* The **default gateway** is used when traffic needs to leave the local network.
* Routers examine the destination IP address and decide where to forward packets.
* IP is a **connectionless protocol**, meaning it does not establish a dedicated connection before sending each packet.

### What I understood

I learned that IP provides the **logical addressing and routing system** that allows packets to travel from one network to another. A switch mainly handles communication within a local network, while a **router uses IP addresses to move traffic between different networks**.
