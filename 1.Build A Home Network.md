# Configuring a Home Network Setup — What I Understood

A home network allows multiple devices to communicate with each other and access the internet through a **router**.

### Key points I learned

* The **router** connects the local network to the internet.
* Devices can connect to the router using **Ethernet or Wi-Fi**.
* **DHCP** can automatically provide devices with an IP address, subnet mask, default gateway, and DNS server.
* The **default gateway** is normally the router's local IP address and is used when a device needs to communicate outside its own network.
* **DNS** translates domain names into IP addresses so devices can find services on the internet.
* A subnet mask determines which addresses belong to the local network.

### What I understood

When setting up a home network, the router acts as the central point connecting my devices to each other and to the internet. I also learned that **IP addressing, DHCP, DNS, and the default gateway work together** to allow a device to communicate beyond its local network.
