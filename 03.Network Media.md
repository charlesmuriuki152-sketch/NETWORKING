# Network Media — What I Understood

Network media is the way data physically travels from one network device to another. In the lab, I worked mainly with different types of **Ethernet cables** and learned that the correct cable depends on the devices being connected.

### Key points I learned

* **Copper Ethernet cables** use electrical signals to carry data.
* **Straight-through cables** are traditionally used to connect different types of devices, such as a PC to a switch.
* **Crossover cables** were traditionally used to connect similar devices, such as switch-to-switch connections.
* The cable connects to specific **interfaces/ports** on the network devices.
* The physical connection must be correct and the interfaces must be active for communication to work.

### What I observed in Packet Tracer

I connected PCs and switches using different Ethernet cables and tested communication using **ping**.

I also noticed that the cable type is not the only thing that determines whether communication works. The devices, interfaces, and network configuration also matter.

### What I understood

The main thing I learned is that **network media forms the physical path through which data travels**. Understanding the different media and how devices connect to each other is important before moving on to more advanced networking concepts.
