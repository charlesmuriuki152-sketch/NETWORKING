# IPv6 Addressing Format and Rules

IPv6 uses **128-bit addresses**, written in hexadecimal and separated into **eight groups**.

Example:

```text
2001:0db8:0000:0000:0000:ff00:0042:8329
```

Each group contains up to **4 hexadecimal characters** (`0–9` and `a–f`).

## Main Rules I Learned

### 1. Leading zeros can be removed

```text
2001:0db8:0000:0000:0000:ff00:0042:8329

2001:db8:0:0:0:ff00:42:8329
```

### 2. Consecutive groups of zeros can be replaced with `::`

```text
2001:db8:0:0:0:ff00:42:8329

2001:db8::ff00:42:8329
```

The `::` can only be used **once** in an IPv6 address.

### 3. IPv6 has no broadcast address

Unlike IPv4, IPv6 uses **multicast** for sending traffic to multiple devices.

### 4. The prefix identifies the network

For example:

```text
2001:db8:1234:1::/64
```

The `/64` means the first 64 bits represent the network prefix, while the remaining 64 bits are normally used for the interface ID.

## What I Understood

The biggest difference I noticed is that IPv6 is much larger than IPv4 and uses hexadecimal notation. The zero-compression rules make long addresses easier to read, while the `/64` prefix helps identify which network an address belongs to.
