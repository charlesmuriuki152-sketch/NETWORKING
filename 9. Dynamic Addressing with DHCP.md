# 🌐 What I Learned About DHCP

## 📖 Overview

I learned that DHCP (Dynamic Host Configuration Protocol) automatically assigns IP addresses and other network settings to devices, making network configuration easier and reducing the need for manual IP assignment.

## ⚙️ How DHCP Works (DORA)

I understood the four steps involved in DHCP address assignment:

* **Discover:** The client searches for a DHCP server.
* **Offer:** The server offers an available IP address.
* **Request:** The client requests the offered address.
* **ACK:** The server confirms the assignment.

## 💻 Cisco DHCP Configuration

I learned how to configure a Cisco router to assign IP addresses automatically using a DHCP pool.

```cisco
ip dhcp pool LAN_POOL
 network 192.168.1.0 255.255.255.0
 default-router 192.168.1.1
 dns-server 8.8.8.8
```

## 🔍 Verification Commands

I also learned how to check DHCP address assignments and configuration using:

```cisco
show ip dhcp binding
show ip dhcp pool
show running-config
```

## ✅ Key Takeaways

* DHCP automates IP address assignment.
* DORA explains how a client obtains an IP address.
* A Cisco router can act as a DHCP server.
* DHCP makes network management easier and reduces manual configuration errors.
