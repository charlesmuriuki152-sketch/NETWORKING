# Cisco Packet Tracer Lab Files

This folder contains Cisco Packet Tracer activity and network-security lab files.

## Files

- `1.1.6-packet-tracer-tutored-activitys-logical-and-physical-mode-exploration.pksz` — logical and physical mode exploration.
- `NetworkSecurityLab1.pkt` — network security configuration practice.

## How to use

1. Install Cisco Packet Tracer 8.0 or later.
2. Open the `.pkt` or `.pksz` file in Cisco Packet Tracer.
3. Review the topology and device configurations.
4. Test connectivity and document your observations.
