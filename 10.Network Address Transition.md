# LAB 10: Network Address Translation (NAT)

## 🎯 Objective
Explore how NAT enables private network devices to communicate with external networks.

## 🛠️ Lab Tasks
- Configure a wireless router and connect four PCs.
- Use DHCP to assign private IP addresses.
- Generate HTTP traffic to an external web server.
- Observe NAT translation using Packet Tracer Simulation mode.

## 🔍 Key Concept
**NAT translates private IP addresses into an external-facing IP address**, allowing devices on a private network to access external resources.
