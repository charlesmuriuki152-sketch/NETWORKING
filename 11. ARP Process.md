## # 🌐 Networking Labs

This repository contains hands-on networking labs and practical exercises completed using Cisco Packet Tracer.

## 📁 Lab Projects

* **ARP – Identify MAC and IP Addresses:** Exploring ARP resolution between devices on local and remote networks.

## 🛠️ Tools

* Cisco Packet Tracer
* Networking protocols: ARP, IPv4, ICMP

## 🎯 Goal

To develop practical networking skills in network communication, addressing, and troubleshooting.
